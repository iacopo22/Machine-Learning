This repository contains my solutions to the four problem sets of the Machine Learning Foundations course (M.A. Quantitative Economics and Finance, University of St. Gallen). Each assignment implements core methods largely from scratch in Python and validates them against reference implementations. Assignment 1 covers gradient descent and stochastic-gradient Ridge regression; Assignment 2 applies discriminant analysis, logistic regression, and tree ensembles to Bitcoin price-direction classification; Assignment 3 builds a Minkowski-norm k-NN classifier with random projections; Assignment 4 analyses multi-armed bandit policies (ε-greedy, UCB, MOSS, Thompson Sampling) and their regret.
